# Property Ledger

A single-user, local-first property bookkeeping app for Windows 11.

## Open it

Double-click `index.html`, then choose your browser (Microsoft Edge is ideal). No installation, account, or internet connection is needed.

## Included

- Add and select properties
- Record income and expenses by property, date, and category
- See portfolio and individual-property income, expenses, and net profit
- Filter transactions by date
- Run a property profit-and-loss report and print it or save it as a PDF
- Export a JSON backup and import it later

Your entries are saved in that browser's local storage on this PC. Export a backup regularly, especially before clearing browser data or changing computers.

## Next desktop step

Once the workflow feels right, this can be packaged as an installable Windows application and given automatic backups. Its basic data and screen structure can also be carried forward to an iPhone/Android version.
